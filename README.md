# Telecom-Customer-churn-analysis-using-power-bi

A data-driven customer churn analysis project built to identify churn patterns, customer retention trends, and key business risk factors using interactive visualizations and analytics.

# Project Overview

Customer churn is one of the biggest challenges for subscription-based businesses. This project analyzes customer behavior data to uncover why customers leave and what factors influence retention.

## The dashboard provides insights into:

- Overall churn rate

- Retained vs churned customers

- Contract-based churn patterns

- Monthly charges analysis

- Risk segmentation

- Customer retention overview

- Tenure and service-based churn trends

# Key Insights

*Overall Metrics*

- Total Customers: 7043

- Churn Rate: 27%

- Churned Customers: 1869

***Contract Type Analysis***

Customers with Month-to-Month contracts show the highest churn rate compared to yearly contracts.

***Risk Segmentation***

Normal Risk Customers: 4541

High Risk Customers: 633

***Tenure Insights***

Customers in the 0–6 months tenure range are more likely to churn.

***Service Impact***

Customers without services like:

- Online Security

- Online Backup

show higher churn tendencies.
